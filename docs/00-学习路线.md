## 一、先搞清楚：LangGraph 到底是什么

一句话：**LangGraph 是一个用来编排「有状态、多步骤」AI 应用的运行时。**

拆开来看三个关键词：

| 关键词 | 含义 | 没有它会怎样 |
|---|---|---|
| 有状态 | 应用要记住中间结果和历史 | 每次调用都从零开始，Agent 无法多轮工作 |
| 多步骤 | 一次任务要经过很多环节 | 单次 API 调用搞不定复杂任务 |
| 运行时 | 负责执行、暂停、恢复、持久化 | 你得自己写 while 循环 + 存数据库 + 错误恢复 |

它和"手写一个 while 循环调大模型"的本质区别在于：**LangGraph 把控制流和数据流都变成了可持久化、可观察、可中断的一等公民。**

看一个最直观的例子：

```
普通写法：                                  LangGraph 写法：

    while True:                                START ──▶ [agent] ──▶ ...
        r = llm(messages)                            ▲          │
        if r.tool_calls:                             └── [tools] ◀┘
            messages.append(exec(r))
        else:
            break

    进程一挂，全丢。                            每步都有快照，能恢复。
    想加审批？自己写状态机。                     加 interrupt 就行。
    想并行？自己开线程。                         连两条边就行。
```

## 二、学习顺序（十课 + 实战）

课程设计成**严格递进**：每一课都建立在前一课之上，且都是可运行的代码。

### 第一阶段：跑起来（第 01–03 课）

| 课程 | 解决的核心问题 | 关键概念 |
|---|---|---|
| **01** 基础聊天机器人 | 怎么把程序写成一张图 | `StateGraph`、`State`、节点、边、`compile()` |
| **02** 工具调用 | 怎么让模型能用工具 | `@tool`、`bind_tools`、`ToolNode`、**ReAct 循环** |
| **03** 记忆持久化 | 怎么让它记住你说的话 | `checkpointer`、`thread_id`、状态快照 |

> 学完这三课，你已经能写出一个**能用的聊天机器人**了。

### 第二阶段：做扎实（第 04–06 课）

| 课程 | 解决的核心问题 | 关键概念 |
|---|---|---|
| **04** 人机协同 | 危险操作怎么让人把关 | `interrupt()`、`Command(resume=...)` |
| **05** 自定义状态 | 数据怎么组织才不乱 | 多字段 State、**自定义 reducer** |
| **06** 流式输出 | 怎么让体验能接受 | 四种 `stream_mode`、`get_stream_writer` |

> 学完这三课，你的应用已经具备**生产可用性**的基本要素。

### 第三阶段：上强度（第 07–09 课）

| 课程 | 解决的核心问题 | 关键概念 |
|---|---|---|
| **07** 控制流 | 流程怎么变复杂 | 多路分支、**并行**、`Send` map-reduce |
| **08** 子图与时间旅行 | 代码怎么复用、怎么回滚 | 子图、`get_state_history`、`update_state` |
| **09** 多智能体 | 任务太大一个人干不完 | **Supervisor**、结构化输出、`recursion_limit` |

> 学完这三课，你已经能设计**复杂 Agent 系统**的架构了。

### 第四阶段：看透本质（第 10 课 + 实战）

| 内容 | 解决的核心问题 |
|---|---|
| **10** 手写 Agent | 把 `ToolNode` / `tools_condition` 全部拆掉，手写一遍 |
| **实战项目** | 把十课能力串成一个真正能用的命令行助理 |

> 学完第 10 课，你再看任何 Agent 框架，都能一眼看穿它在干什么。

## 三、怎么用这个项目

### 1. 跑起来看看（不需要 API Key）

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# macOS / Linux
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

然后：

```bash
python verify_all.py                            # 一键跑通全部课程（15 秒左右）
python lessons/01_basic_chatbot.py              # 单独看第一课
python lessons/01_basic_chatbot.py --interactive  # 自己跟它对话
```

> **重要**：项目内置了「离线模拟模型」，**没有 API Key 也能把十课全部跑通**。
> 它的接口和真模型完全一样，所以你学到的知识 100% 可以迁移。
> 想接真模型时，把 `.env.example` 复制成 `.env` 填上 Key 即可，**一行代码都不用改**。

### 2. 推荐的学习方法

```
① 先跑一遍        python lessons/0X_xxx.py
     ↓
② 读代码注释      每节课的注释都是"讲解稿"，不是"说明文档"
     ↓
③ 读对应原理文档  docs/ 目录，理解"为什么这么设计"
     ↓
④ 做动手练习      每节课最后的「动手练习」——这一步最关键
     ↓
⑤ 进交互模式      --interactive，亲眼看它的真实表现
```

**⚠️ 只做①②不做④，等于没学。** 编程是手上的功夫，不是眼睛的功夫。

### 3. 遇到问题

- 报错了 → 先看 [`docs/08-常见问题与排错.md`](./08-常见问题与排错.md)
- 概念绕不清 → 看对应的 `docs/` 原理文档
- 想知道"这在真实项目里怎么用" → 看 `capstone/assistant.py`

## 五、学完之后，你应该能回答这些问题

用这些问题自测。**能讲清楚，才算真学会。**

**基础层**
- [ ] `State`、`Node`、`Edge` 分别是什么？各自解决了什么问题？
- [ ] 为什么节点函数要"返回增量"而不是"修改 state"？
- [ ] reducer 是什么？有它和没它的区别是什么？

**核心层**
- [ ] 什么是 ReAct 循环？为什么需要"回环边"？
- [ ] `bind_tools` 和 `ToolNode` 分别在做什么？为什么说它们是两件事？
- [ ] Checkpointer 是怎么实现"记忆"的？`thread_id` 起什么作用？
- [ ] `interrupt()` 暂停之后，图是怎么恢复的？为什么说它是"重放"而不是"继续"？

**进阶层**
- [ ] 什么是超级步（superstep）？并行分支为什么互相看不见对方？
- [ ] 并行分支写同一个字段时，为什么必须配 reducer？
- [ ] 子图的状态怎么和父图打通？两种方式各适合什么场景？
- [ ] Supervisor 多智能体里，怎么防止主管"转圈"派活？

**本质层**
- [ ] 如果不用 LangGraph，用纯 Python 怎么实现一个 Agent？（第 10 课）
- [ ] `ToolNode` 内部大概做了什么？你能自己写一个吗？
- [ ] 为什么 `ToolMessage` 必须带 `tool_call_id`？
